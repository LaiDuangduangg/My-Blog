## 题目描述

给你一个长度为 `N` 的字符串 `S`，全部是小写英文字母。

接下来要处理 `Q` 个查询，分两种类型：

- 类型 1：把字符串 `S` 中第 `i_q` 个字符改成 `c_q`。（如果本来就是 `c_q`，那就别动它。）
- 类型 2：统计并输出字符串 `S` 中，从第 `l_q` 个字符到第 `r_q` 个字符（包含两端）之间，有多少种不同的字母。

## 约束条件

- `N`、`Q`、`i_q`、`l_q`、`r_q` 都是整数。
- `S` 是只包含小写英文字母的字符串。
- `c_q` 是小写英文字母。
- `1 ≤ N ≤ 500000`
- `1 ≤ Q ≤ 20000`
- `|S| = N`
- `1 ≤ i_q ≤ N`
- `1 ≤ l_q ≤ r_q ≤ N`
- 每个测试用例至少有一个类型为 2 的查询。

## 输入格式

输入从标准输入读取，格式如下：

```text
N
S
Q
Query_1
⋮
Query_Q
```

其中，第 `4` 行到第 `(Q + 3)` 行的 `Query_i` 是下面两种格式之一：

```text
1 i_q c_q
```

```text
2 l_q r_q
```

## 输出格式

对于每个类型为 2 的查询，输出一行答案。

## 样例

### Input

```text
7
abcdbbd
6
2 3 6
1 5 z
2 1 1
1 4 a
1 7 d
2 1 7
```

### Output

```text
3
1
5
```

## 样例解释

第一个查询中，字符串 `cdbb` 包含三种不同字母：`b`、`c` 和 `d`，所以输出 `3`。

第二个查询后，`S` 变成了 `abcdzbd`。

第三个查询中，子串 `a` 只有一种字母：`a`，输出 `1`。

第四个查询后，`S` 变成了 `abcazbd`。

第五个查询没有改变字符串，仍是 `abcazbd`。

第六个查询中，字符串 `abcazbd` 包含五种不同字母：`a`、`b`、`c`、`d` 和 `z`，所以输出 `5`。


## 代码如下：
```cpp
#include <bits/stdc++.h>
using namespace std;

int n, q;
string s;
constexpr int MAXN = 1 << 25;
vector <char> arr;
vector <long long> mask;

int countt (long long mask) {
    int cnt = 0;
    for (int i = 0; i < 30; i ++) {
        if (mask & (1LL << i)) {
            cnt ++;
        }
    }
    return cnt;
}

void PushUp (int i) {
    mask[i] = mask[i << 1] | mask[i << 1 | 1];
}

void build (int l, int r, int i) {
    if (l == r) {
        int pos = s[l] - 'a';
        mask[i] |= (1 << pos);
        return;
    }

    int mid = (l + r) >> 1;
    build (l, mid, i << 1);
    build (mid + 1, r, i << 1 | 1);
    PushUp (i);
}

void update (int jobi, char jobv, int l, int r, int i) {
    if (l == r) {
        if (s[jobi] != jobv) {
            int cur_pos = jobv - 'a';
            mask[i] = (1LL << cur_pos);
            s[jobi] = jobv;
        }
        return;
    }

    int mid = (l + r) >> 1;
    if (jobi <= mid) {
        update (jobi, jobv, l, mid, i << 1);
    }
    if (jobi > mid) {
        update (jobi, jobv, mid + 1, r, i << 1 | 1);
    }
    PushUp (i);
} 

long long query (int jobl, int jobr, int l, int r, int i) {
    if (jobl <= l && r <= jobr) {
        return mask[i];
    }

    long long ans = 0;
    int mid = (l + r) >> 1;
    if (jobl <= mid) {
        ans |= query (jobl, jobr, l, mid, i << 1);
    }
    if (jobr > mid) {
        ans |= query (jobl, jobr, mid + 1, r, i << 1 | 1);
    }
    return ans;
}

int main ()
{
    ios::sync_with_stdio (false);
    cin.tie (0);

    cin >> n >> s >> q;
    s = " " + s;

    mask.assign (n << 2, 0);
    build (1, n, 1);
    for (int i = 0; i < q; i ++) {
        int op;
        cin >> op;

        if (op == 1) {
            int pos;
            char c;
            cin >> pos >> c;
            update (pos, c, 1, n, 1);
        }
        if (op == 2) {
            int l, r;
            cin >> l >> r;
            int ans = query (l, r, 1, n, 1);
            cout << countt(ans) << '\n';
        }
    }
    return 0;
}
```
