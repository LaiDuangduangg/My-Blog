# 题目描述

Alice 和 Bob 拥有一棵有 $n$ 个顶点的树，顶点编号从 $1$ 到 $n$。他们决定在这棵树上轮流进行游戏，Alice 先手。

在每次操作中，玩家可以选择两个相邻的顶点 $u$ 和 $v$，并将所有连接到 $u$ 的边（连接 $u$ 和 $v$ 的边除外）改为连接到 $v$。

简而言之，操作后，每条满足 $w \ne v$ 的边 $(u,w)$ 都会变为 $(v,w)$。


## 图示:
![操作示意图](/images/4e7b1388eb3d91e3a6823e232cdcb6a9.png)

然而，他们很快意识到这样的操作可能会导致游戏永远无法结束，因此增加了一条额外规则：操作前后的两棵树不能同构。

更正式地说，设 $V(S)$ 为树 $S$ 的顶点集，$V(T)$ 为树 $T$ 的顶点集。如果存在一个双射 $f: V(S) \to V(T)$，使得对于 $V(S)$ 中的所有顶点对 $(u,v)$，$u$ 和 $v$ 在 $S$ 中有边相连，当且仅当 $f(u)$ 和 $f(v)$ 在 $T$ 中有边相连，则称树 $S$ 和树 $T$ 同构。$f(s)=t$ 意味着 $S$ 中的顶点 $s$ 对应于 $T$ 中的顶点 $t$。

当一名玩家无法进行任何有效操作时，另一名玩家获胜。假设 Alice 和 Bob 都足够聪明，并且会采取最优策略来获胜；若无法获胜，则会阻止对手获胜。请预测获胜者。

## 输入格式

第一行包含一个整数 $n$（$2 \le n \le 50$），表示树的顶点数。

接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$（$1 \le u,v \le n$），表示连接顶点 $u$ 和顶点 $v$ 的一条无向边。

保证给定的边构成一棵树。

## 输出格式

如果 Alice 将赢得游戏，输出 “Alice”。

如果 Bob 将赢得游戏，输出 “Bob”。

如果即使增加额外规则后，双方都采取最优策略，游戏仍永远不会结束，输出 “Draw”。

## 样例

### 样例输入 1

```text
4
1 2
2 3
3 4
```

### 样例输出 1

```text
Alice
```

### 样例输入 2

```text
4
1 2
1 3
1 4
```

### 样例输出 2

```text
Bob
```

## 题解思路：

1. 可以先手动模拟一下，毕竟这道题除了数据结构有这个操作以外有着特殊的树抽象了，尤其是那个同构（但学过有机化学的都知道同构的意思，这里不过多的作解释。

2. 这里提供一些可用性的方向，尤其是遇到一些树上博弈问题的时候：

   （1）某个点或某些点的入度是否改变

   （2）叶子数量是否改变。

   （3）边数或连通块数是否改变

3. 本题的操作：选中两个相邻点，并把其中一个点的邻居接到另一个节点身上，这样就会导致被选节点变得光亮，也就是自己变成了一个叶子节点，两人轮流操作，每轮造出一个新的叶子节点，但是点又是有限的，因此只需要统计叶子节点数 (即入度==1 的点数即可)

4. 关于同构：当且仅当选中的2个点中有叶子节点才会出现同构。有了这个规则，即不能选中叶子节点，树上就再也不会陷入死循环。


## 代码如下:
```cpp
#include <bits/stdc++.h>
using namespace std;

int main ()
{
    int n;
    cin >> n;

    vector <int> deg (n + 1);
    for (int i = 1; i < n; i ++) {
        int u, v;
        cin >> u >> v;

        deg[u] ++;
        deg[v] ++;
    }
    int cnt = 0;
    for (int i = 0; i <= n; i ++) {
        if (deg[i] >= 2) {
            cnt ++;
        }
    }
    if (cnt >= 2 && cnt % 2 == 0) {
        cout << "Alice" << '\n';
    }
    else {
        cout << "Bob" << '\n';
    }
    return 0;
}
```
