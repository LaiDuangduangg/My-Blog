Noir 有 $n$ 个宝石。第 $i$ 个宝石上写有一个正整数 $a_i$。Noir 想要将这些宝石分成若干个非空的组。每个宝石恰好属于一个组。

假设第 $i$ 个组包含编号为 $k_{i,1}, k_{i,2}, \ldots, k_{i,p}$ 的宝石，那么 Noir 将第 $i$ 个组的亮度视为

$$
a_{k_{i,1}} \oplus a_{k_{i,2}} \oplus \cdots \oplus a_{k_{i,p}},
$$

其中 $\oplus$ 是按位异或（XOR）运算。记第 $i$ 个组的亮度为 $B_i$。

对于一个包含 $m$ 个组的分组方案，Noir 将该方案的价值视为

$$
B_1 \mathbin{\&} B_2 \mathbin{\&} \cdots \mathbin{\&} B_m,
$$

其中 $\&$ 是按位与（AND）运算。

Noir 想要找到所有分组方案中可能的最大价值。

## 输入格式

输入包含多个测试用例。输入的第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试用例的数量。

对于每个测试用例：第一行包含一个整数 $n$（$1 \le n \le 5 \times 10^5$），表示宝石的数量。第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i < 2^{60}$），表示写在宝石上的整数。

保证所有测试用例中 $n$ 的总和不超过 $5 \times 10^5$。

## 输出格式

对于每个测试用例，输出一个整数，表示所有分组方案中可能的最大价值。

## 样例

### 输入

```
4
4
1 2 3 1
6
4 7 5 2 6 3
4
14 15 9 18
2
251508091405 13011908091815
```

### 输出

```
2
6
26
13121614001578
```

## 说明

对于第一个测试用例，一种可能的分组方案是 $[1,2,3,1] = [1,3],[2,1]$，其价值为

$$
B_1 \mathbin{\&} B_2 = (1 \oplus 3) \mathbin{\&} (2 \oplus 1) = 2 \mathbin{\&} 3 = 2.
$$

另一种可能的分组方案是 $[1,2,3,1] = [1,2,3,1]$，其价值较低，为

$$
B_1 = 1 \oplus 2 \oplus 3 \oplus 1 = 1.
$$

可以证明，无法获得大于 $2$ 的价值。

对于第二个测试用例，最优分组方案是 $[4,7,5,2,6,3] = [7],[5,3],[6],[4,2]$，其价值为

$$
7 \mathbin{\&} (5 \oplus 3) \mathbin{\&} 6 \mathbin{\&} (4 \oplus 2) = 6.
$$


# 题目解析

## 1. 操作概要

题目中说明，在 $a$ 数组中，每个数可以任意分组，且组内异或、组间与操作。

如何使得总值最大？异或最大值很容易让人想到线性基；但这题最难处理的部分是组间与（`&`）。如果要转化为线性基，需要先将式子处理成：

$$
(x_1\oplus x_2\oplus\cdots\oplus x_m)\ \&\ (\cdots\oplus\cdots\oplus\cdots)
$$

这样的形式。

## 2. 条件推导

一个数组最初始的情况为：

$$
a_1\ \&\ a_2\ \&\ a_3\ \&\ \cdots\ \&\ a_n=Val
$$

即每个数自成一组，不存在组内异或的情况。

假设在某一位上：

```text
a1: 1---
a2: 1---
a3: 1---
a4: 1---
```

不进行任何合并时，这一位与后的值（最高位）为 $1$。

为了不损害最高位，只能选取其中奇数个该位为 $1$ 的数分为一组进行异或。这样组内异或结果在这一位仍然为 $1$，从而不损害最高位。

例如合并前三个数后，结果变为：

$$
B_1\ \&\ a_4
$$

仅考虑这一位即可。

同时考虑该位为 $0$ 的情况。例如：

```text
a1: -0--
a2: -0--
a3: -1--
a4: -1--
```

若不进行合并，则该位的与结果为 $0$。

若将前三个数合并，则：

$$
(0\oplus0\oplus1)\ \&\ 1=1
$$

这一步操作是有收益的。

再考虑另一种情况：

```text
0, 1, 1, 1
```

不合并时：

$$
1\ \&\ 1\ \&\ 1\ \&\ 0=0
$$

合并时：

$$
(1\oplus1\oplus1)\ \&\ 0=0
$$

合并后仍然为 $0$，不赚不赔。

因此，考虑所有情况：

1. 当个数为偶数时，可以不断合并奇数个数的组，直到最终变为两组。每次操作的收益只增不减。
2. 当个数为奇数时，可以不断合并奇数个数的组，直到最终变为一组。每次操作的收益只增不减。

例如：

```text
a1: --1--
a2: --1--
a3: --0--
a4: --1--
a5: --1--
```

为了只赚不赔，只能考虑合并其中的奇数个数：

$$
a_1\oplus a_2\oplus a_3=B_1
$$

之后为：

$$
B_1\ \&\ a_4\ \&\ a_5
$$

合并为一组后，该位仍然为 $1$，不会损失。

再考虑：

```text
a1: --1--
a2: --1--
a3: --0--
a4: --0--
a5: --1--
```

此时：

$$
(1\oplus1\oplus0)\ \&\ 0\ \&\ 1=0
$$

因此，当 $n$ 为偶数时，一路合并为两组，只赚不赔；当 $n$ 为奇数时，一路合并为一组，只赚不赔。

## 3. 转化为线性基

于是，问题可以转化为：

$$
(\cdots\oplus\cdots\oplus\cdots)\ \&\ (\cdots\oplus\cdots\oplus\cdots)
$$

的最大值。

这个式子包含分成一组或两组的所有情况。若要使其最大化，就可以转化为线性基问题。

令其中一部分为 $u$，并令：

$$
X=a_1\oplus a_2\oplus a_3\oplus\cdots\oplus a_n
$$

那么另一部分为：

$$
X\oplus u
$$

因此需要最大化：

$$
u\ \&\ (X\oplus u)
$$

化简：

$$
\begin{aligned}
u\ \&\ (X\oplus u)
&=u\ \&\ X\oplus u\ \&\ u\\
&=u\ \&\ X\oplus u\ \&\ \text{all1}\\
&=u\ \&\ (X\oplus\text{all1})\\
&=u\ \&\ (\sim X)
\end{aligned}
$$

而：

$$
u=c_1a_1\oplus c_2a_2\oplus c_3a_3\oplus\cdots\oplus c_na_n
$$

其中 $c_i$ 为 $0$ 或 $1$。

因此：

$$
\begin{aligned}
u\ \&\ (\sim X)
&=(c_1a_1\oplus c_2a_2\oplus\cdots\oplus c_na_n)\ \&\ (\sim X)\\
&=c_1a_1\ \&\ (\sim X)\oplus c_2a_2\ \&\ (\sim X)\oplus\cdots\oplus c_na_n\ \&\ (\sim X)
\end{aligned}
$$

此时已经变成了线性基的基本形式。

因此，将：

$$
a_i\ \&\ (\sim X)
$$

插入线性基即可。


## 代码如下:
```cpp
#include <bits/stdc++.h>
using namespace std;

void Insert (long long x, vector <long long> &b) {
    for (int i = 59; i >= 0; i --) {
        if ((x & (1LL << i)) == 0)  continue;
        if (b[i] == 0) {
            b[i] = x;
            return;
        }
        x ^= b[i];
    }
}

long long max_xor_val (long long start, vector <long long> &b) {
    for (int i = 59; i >= 0; i --) {
        if (b[i] == 0)  continue;
        if ((start ^ b[i]) > start) {
            start ^= b[i];
        }
    }
    return start;
}

void solve () {
    int n;
    cin >> n;

    vector<long long> b(70);
    vector<long long> a(n);

    long long X = 0;
    for (int i = 0; i < n; i ++) {
        cin >> a[i];
        X ^= a[i];
    }
    long long mask = ~X;
    long long ans = 0;
    for (int i = 0; i < n; i ++) {
        Insert (a[i] & mask, b);
    }
    ans = max (X, max_xor_val (0, b));
    cout << ans << '\n';
}

int main ()
{
    ios::sync_with_stdio (false);
    cin.tie (0);

    int t;
    cin >> t;

    while (t --) {
        solve ();
    }
    return 0;
}
```
