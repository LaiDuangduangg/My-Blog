## 问题描述:

Menji 博士是人工智能领域的专家。现在，他正在训练 Bot，一个 AGI（通用人工智能）。

为了教 Bot 如何玩游戏，他每天都和 Bot 一起玩游戏。今天他们正在玩以下游戏：

游戏开始时有一个包含 $2n$ 个非负整数的序列

$$
a_1,a_2,\ldots,a_{2n},
$$

以及一个数字 $S$。初始时，$S=0$。

Menji 和 Bot 轮流进行操作，Menji 先手：

- 在 Menji 的回合中，他从序列中选择一个数字 $x$，令 $S\leftarrow S\oplus x$，并从序列中删除 $x$。其中，$\oplus$ 表示按位异或（XOR）运算。
- 在 Bot 的回合中，他从序列中选择一个数字 $x$，并从序列中删除 $x$。

当序列中没有数字剩余时，游戏结束。当且仅当最终 $S=0$ 时 Menji 获胜；否则 Bot 获胜。

Menji 想知道，如果双方都采取最优策略，谁会赢得游戏。

## 输入格式

输入包含多个测试用例。

第一行包含一个整数 $T$（$1\le T\le10^5$），表示测试用例的数量。

对于每个测试用例：

- 第一行包含一个整数 $n$（$1\le n\le10^5$），含义如题面所述。
- 第二行包含 $2n$ 个整数 $a_1,a_2,\ldots,a_{2n}$（$0\le a_i<2^{30}$），表示游戏中的整数。

保证所有测试用例中 $n$ 的总和不超过 $2\times10^5$。

## 输出格式

对于每个测试用例：

- 如果 Menji 能赢得游戏，输出一行 `Menji`；
- 否则，输出一行 `Bot`。

## 样例

### 输入

```text
5
2
1 1 3 3
2
1 1 1 3
3
1 1 4 5 1 4
3
1 9 1 9 8 10
6
1 1 4 5 1 4 1 9 1 9 8 10
```

### 输出

```text
Bot
Menji
Menji
Menji
Bot
```

## 说明

对于第一个测试用例，无论 Menji 选择什么数字，Bot 总是可以选择一个相同的数字。因此 Menji 最终总会选择一个 $1$ 和一个 $3$，于是

$$
S=1\oplus3=2\ne0,
$$

所以 Bot 总能获胜。

对于第二个测试用例，Menji 可以在第一回合选择一个 $1$。无论 Bot 选择什么数字，Menji 都可以再选择另一个 $1$。因此 Menji 总能得到两个 $1$，于是

$$
S=1\oplus1=0,
$$

所以 Menji 总能获胜。



## 题目思路

Menji 最终会取走恰好 $n$ 个数，她获胜当且仅当这些数的异或和为 $0$。

由于 Bot 总是在 Menji 之后操作，我们先考虑：**Menji 取走一个数后，Bot 能否立即作出一个有规律的回应？**

如果存在两个相同的数 $(x,x)$，Bot 可以把它们预先配成一对。当 Menji 取走其中一个 $x$ 时，Bot 立即删除另一个 $x$。这样 Menji 会从这一对中恰好得到一个 $x$。

因此，应当先将相同数字尽量两两配对，再研究配对后剩下的数字。

需要注意，配对策略并不是 Bot 唯一的策略。我们使用它，是因为在证明 Bot 必胜时，只需构造出一种能够应对 Menji 所有走法的策略。

## 化简局面

设数字 $x$ 出现了 $c_x$ 次，将其写成

$$
c_x=2q_x+r_x
$$

这表示 $x$ 可以组成 $q_x$ 对，并且还可能剩下一个单独的 $x$。

如果 Menji 从每一对中恰好得到一个数，那么这些数对对她最终异或和的贡献为

$$
P=\bigoplus_{q_x\text{ 为奇数}}x.
$$

只有 $q_x$ 为奇数时，$x$ 才会在 $P$ 中出现。等价地，当

$$
c_x\bmod 4\in\{2,3\}
$$

时，需要令 $P\gets P\oplus x$。

将所有出现奇数次的数字放入集合 $R$。每种数字在 $R$ 中至多出现一次，因此 $R$ 中的数字两两不同。

由于原序列有偶数个元素，所以 $|R|$ 也是偶数，只可能为

$$
0,2,4,6,\ldots
$$

接下来只需分类讨论 $R$。

## 情况一：$|R|=0$

此时所有数字都已组成相同数对。

如果 $P=0$，Menji 可以使用“空位策略”：

1. 先从任意完整数对中取走一个数，将另一个数作为空位；
2. 如果 Bot 删除某个完整数对中的一个数，Menji 就取走这一对中的另一个数；
3. 如果 Bot 删除空位，Menji 就打开一个新的完整数对，并将其另一个数作为新空位。

这样 Menji 最终会从每个数对中恰好得到一个数，因此最终异或和为 $P=0$。

如果 $P\ne0$，Bot 将所有相同数字预先配对。Menji 每取走一对中的一个数，Bot 就删除另一个。于是无论 Menji 如何选择，她的最终异或和都被固定为 $P\ne0$。

所以

$$
|R|=0\quad\Longrightarrow\quad
\text{Menji 获胜当且仅当 }P=0.
$$

## 情况二：$R=\{u,v\}$

如果 $P=u$，Menji 先取走 $u$，将 $v$ 作为空位，再对所有相同数对使用空位策略。最终异或和为

$$
u\oplus P=u\oplus u=0.
$$

当 $P=v$ 时同理。

反之，Bot 可以把所有相同数字分别配对，再将 $u,v$ 配成一对。Menji 每取一个数，Bot 就删除其配对元素。这样 Menji 最终只能得到

$$
P\oplus u
$$

或

$$
P\oplus v.
$$

如果 $P\ne u$ 且 $P\ne v$，这两个结果都不为 $0$。

所以

$$
R=\{u,v\}\quad\Longrightarrow\quad
\text{Menji 获胜当且仅当 }P=u\text{ 或 }P=v.
$$

## 情况三：$|R|\ge4$

此时 Bot 必胜。

证明下面的引理：

> 对于至少四个、数量为偶数且两两不同的数字，无论指定什么目标异或值 $T$，Bot 都能阻止 Menji 得到 $T$。

当只剩四个不同数字时，Menji 先取走 $x$。她之后还会再取一个数；如果最终异或要等于 $T$，第二个数必须为

$$
y=T\oplus x.
$$

如果 $y$ 仍在剩余数字中，Bot 立即删除 $y$；否则 Menji 本来就无法得到目标 $T$，Bot 任意删除一个数即可。

对于六个或更多不同数字，Menji 先取走 $x$，Bot 任意删除另一个数。剩余数字仍然至少有四个，而 Menji 在剩余局面中的目标变为 $T\oplus x$，根据归纳假设，Bot 仍然能够阻止她。

回到原问题，相同数对的贡献被 Bot 固定为 $P$。若最终总异或为 $0$，Menji 必须让自己从 $R$ 中取得的数字异或为 $P$。根据上述引理，Bot 可以阻止这个目标。

因此

$$
|R|\ge4\quad\Longrightarrow\quad\text{Bot 获胜}.
$$

## 最终判定

- $R$ 为空：当且仅当 $P=0$ 时，Menji 获胜；
- $R=\{u,v\}$：当且仅当 $P=u$ 或 $P=v$ 时，Menji 获胜；
- $|R|\ge4$：Bot 获胜。

## 样例解释

1. $[1,1,3,3]$

   $$
   P=1\oplus3=2,\qquad R=\varnothing.
   $$

   因为 $P\ne0$，所以 Bot 获胜。

2. $[1,1,1,3]$

   $$
   P=1,\qquad R=\{1,3\}.
   $$

   因为 $P=1\in R$，所以 Menji 获胜。

3. $[1,1,4,5,1,4]$

   $$
   P=1\oplus4=5,\qquad R=\{1,5\}.
   $$

   因为 $P=5\in R$，所以 Menji 获胜。

4. $[1,9,1,9,8,10]$

   $$
   P=1\oplus9=8,\qquad R=\{8,10\}.
   $$

   因为 $P=8\in R$，所以 Menji 获胜。

5. $[1,1,4,5,1,4,1,9,1,9,8,10]$

   $$
   P=4\oplus9=13,\qquad R=\{1,5,8,10\}.
   $$

   因为 $|R|=4$，所以 Bot 获胜。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve () {
    int n;
    cin >> n;
    vector <int> a (2 * n);
    
    for (int i = 0; i < 2 * n; i ++) {
        cin >> a[i];
    }
    sort (a.begin (), a.end ());
    vector <int> extra_element;
    long long xxor = 0;
    for (int i = 0; i < 2 * n;) {
        int j = i;
        while (j < 2 * n && a[i] == a[j]) {
            j ++;
        }

        int cur = a[i];
        int cnt = j - i;
        int group = cnt / 2;
        int remainder = cnt % 2;

        if (group % 2 == 1) {
            xxor ^= cur;
        }
        if (remainder == 1) {
            extra_element.push_back (cur);
        }
        i = j;
    }
    
    bool can_win = false;
    if (extra_element.empty () && xxor == 0) {
        can_win = true;
    } 
    else if (extra_element.size () == 2) {
        if (xxor == extra_element[0] || xxor == extra_element[1]) {
            can_win = true;
        }
    }

    if (can_win) {
        cout << "Menji" << '\n';
    }
    else {
        cout << "Bot" << '\n';
    }
}

int main ()
{
    ios::sync_with_stdio (false);
    cin.tie (0);

    int t;
    cin >> t;

    while (t --) {
        solve ();
    }
    return 0;
}
```

## 复杂度

排序的时间复杂度为 $O(n\log n)$，空间复杂度为 $O(n)$。
